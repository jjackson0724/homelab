## Weekly Collection Routine - 20 Minutes Per Day

| Day | Source | Action |
|---|---|---|
| Monday | CyberGeoDigest + CISA | Check advisories, note TTPs and actors |
| Tuesday | Mandiant or CrowdStrike | Read one post, extract IOCs |
| Wednesday | AlienVault OTX + SANS ISC | Community intel digest |
| Thursday | SCYTHE ThreatThursday + Talos | Download plan, map to ATT&CK, queue for Trinity |
| Friday | DFIR Report + weekly wrap | Log findings in COLLECTION_LOG.md |
| Weekend | Krebs on Security or Decryption Digest | Deeper read, one threat actor profile |
