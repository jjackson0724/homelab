# CTI - Cyber Threat Intelligence

Finished intelligence products, threat actor profiles, and campaign analyses
produced from Matrix homelab exercises.

## Structure

- threat-actors/ - Threat actor profiles using Diamond Model
- campaigns/ - Campaign tracking across exercises
- finished-intel/ - Executive-ready intelligence briefs

## Workflow

1. Select threat actor from CTI_TRACK.md library
2. Pull ATT&CK-mapped TTPs
3. Execute emulation on Trinity
4. Detect on Seraph
5. Write finished intel product and commit here
